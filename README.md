Descripción del proyecto

Este proyecto consiste en una aplicación web desarrollada con Vue.js, Node.js, Express y MySQL.

El sistema permite a los usuarios registrarse e iniciar sesión para acceder a una tienda en línea donde pueden visualizar productos, agregarlos al carrito de compras y generar pedidos.

La aplicación cuenta con autenticación mediante JWT para proteger las rutas y mantener la sesión de los usuarios.

Además, existe un usuario administrador con permisos especiales para gestionar el catálogo de productos, permitiendo agregar y modificar productos desde el sistema.

El frontend fue desarrollado con Vue.js para crear una interfaz dinámica e interactiva, mientras que el backend funciona como una API REST encargada de procesar solicitudes, validar usuarios y conectarse con la base de datos MySQL.

El proyecto implementa una arquitectura cliente-servidor y utiliza roles de usuario para diferenciar las funciones de clientes y administradores.
